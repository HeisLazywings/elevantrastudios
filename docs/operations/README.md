# Elevantra Studios — working system

These are **blank internal-use templates** for the studio's commercial and delivery workflow. They are versioned in a public GitHub repository, so **never enter actual client names, financial terms, private conversation notes, customer data, passwords, or evidence into these tracked files**.

Create a separate, access-controlled working copy for every engagement; keep completed agreements, notes and datasets in approved private storage. These templates are **not published by the website CMS** and do not create a client portal.

## Practical sequence

1. **Qualify the opportunity** in the [sales scorecard](./sales-scorecard.md). Identify a decision-maker, specific commercial problem and buying process before committing to custom work.
2. **Discover the current situation** using [discovery and baseline](./discovery-baseline.md). Agree metric definitions and obtain consent for any client-provided information.
3. **Propose and agree the work** using [scope and agreement](./project-scope-agreement.md). Secure the agreed initial payment, dependencies and approvals before production work starts.
4. **Track each decision** in the [project decision journal](./project-decision-journal.md); send short regular client updates and record approvals.
5. **Test, hand over and review** what was delivered; obtain express permission before naming clients, using screenshots or publishing a case study. Document measured versus estimated changes and limitations.

The studio's six public stages (Discovery → Strategy → Design → Development → Launch → Growth) represent a **typical framework**, not an unconditional promise of deliverables. The signed project scope governs every engagement.

## Guardrails

- Write observations separately from hypotheses, client reports and verified measurements.
- No fabricated conversion, revenue or SEO claims; include the period, source and denominators.
- Never treat silence as substantive approval unless a legally reviewed agreement explicitly provides for it.
- Revisions, ownership, support, payment deadlines and project pauses must be agreed, not assumed.
- Use an adviser familiar with applicable Nigerian law before adopting the agreement as a binding legal form.
