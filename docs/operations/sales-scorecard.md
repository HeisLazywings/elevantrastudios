# Sales and profitability scorecard — private weekly template

Use a separate access-controlled spreadsheet or CRM to store actual client/prospect data. This public-repository file only defines the fields and calculation rules.

## Pipeline stages (each with an exit criterion)

1. **Researched:** a legitimate reachable business and a specific observable opportunity.
2. **Contacted:** a personalized conversation attempt made; record channel/date.
3. **Engaged:** a meaningful two-way exchange about the current process or pain.
4. **Qualified:** documented problem, decision-maker, plausible budget/timing and next step.
5. **Proposal submitted:** project scope, cost, dependencies and follow-up date sent.
6. **Won:** written acceptance and initial payment received (track payment separately if commercial terms differ).
7. **Lost / deferred:** documented reason, no silent recycling as an active deal.

Never count an unanswered DM as an engaged prospect or a verbal “interesting” as a sale.

Useful formulas (only on cohorts with reliable tracking):
- Outreach-to-conversation rate = meaningful replies from the same outreach cohort / delivered first attempts.
- Proposal win rate = accepted proposals / proposals with a decision (won or lost), not merely all sent.
- Qualified-to-deposit rate = qualified leads receiving a deposit within the chosen observation window / qualified leads in that cohort.
- Sales cycle = days from first meaningful conversation to written agreement / deposit; label definition used.
