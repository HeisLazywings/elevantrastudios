# Studio typefaces

These unmodified, self-hosted WOFF2 files preserve the existing Inter and Fraunces
type system without requiring a Google Fonts request during build or page load.

- Inter: Latin variable weight, normal and italic, from
  `@fontsource-variable/inter@5.3.0`.
- Fraunces: Latin full variable axes, normal and italic, from
  `@fontsource-variable/fraunces@5.3.0`.

Both packages were downloaded with `npm pack` from `https://registry.npmjs.org`.
Their npm SHA-512 integrity values were verified during retrieval. The original
SIL Open Font License files are included alongside the fonts.

Upstream: https://github.com/rsms/inter and https://github.com/undercasetype/Fraunces
